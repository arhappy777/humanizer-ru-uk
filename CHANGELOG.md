# Changelog

## 0.4.1 — 2026-07-20

- Инструкция для Custom GPT превращена из сокращённой копии правил в загрузчик: единственный источник правил — полный файл `humanizer-ru-uk-full.md` (Knowledge), инструкция объявляет его главным и несёт только жёсткое ядро (режимы, факт-замок, границы). Ручная выжимка каталога удалена — правилам больше негде разъезжаться, а дизайн не зависит от лимитов полей.
- README уточнён: Knowledge-файл — основной носитель скилла для ChatGPT.

## 0.4.0 — 2026-07-19

- Финальный вопрос-вовлечение («А вы…?», «Согласны?») признан шаблоном: новое правило S27 в каталоге и скрипте; в rewrite такой финал по умолчанию убирается или заменяется вопросом по теме, дословно сохраняется только по явной просьбе автора. Шаблонный финал исходника больше не считается обязательным CTA в факт-замке.
- Новый раздел SKILL.md «Писать по голой теме»: как выполнять запросы вида «составь текст про зиму» без фактов — один угол вместо темы целиком, детали мира вместо открытки, позиция без выдуманной биографии, запрет открыточного тона. Эталон — пример 4 в references/examples.md.
- Компактная инструкция для ChatGPT дополнена обоими правилами.

## 0.3.2 — 2026-07-19

- Эталонный корпус `eval/` и харнес `scripts/eval_corpus.py`: 10 ИИ-постов (от грубых клише до тонких, ловимых только структурными правилами), базовая линия зафиксирована в `eval/README.md`; папка `eval/human/` для своих реальных постов (в git не попадает) — меряет ложные срабатывания.
- Демо реального вывода аудитора в README (`docs/demo.svg`).
- S08: рекламная инфляция теперь ловит все формы «вывести/выведет/вывел на новый уровень» (раньше только «выводит»); аналогично для украинского.

## 0.3.1 — 2026-07-19

- `build_ports.py` переводит stdout/stderr в UTF-8, как это уже делает аудитор: на Windows-консоли с cp1252 вывод кириллицы ронял скрипт (и CI).

## 0.3.0 — 2026-07-19

- Скилл теперь ставится куда угодно: в `dist/` лежат собранные версии для платформ без доступа к файлам — `humanizer-ru-uk-full.md` (SKILL.md + все каталоги одним файлом: ChatGPT Knowledge, claude.ai Project, вставка в чат) и `chatgpt-instructions.md` (компактная инструкция под лимит 8000 знаков поля Instructions Custom GPT).
- Сборщик `scripts/build_ports.py`; актуальность `dist/` проверяют тесты и отдельный шаг CI (`--check`).
- Каталог пополнен `references/examples.md` — эталонные разборы «до → после» для режимов `draft` и `rewrite` (русский и украинский); подключён в SKILL.md.
- Правила площадок расширены: Threads, X (Twitter), VK и длинные посты.
- README: раздел установки для ChatGPT/claude.ai и английский quickstart.

## 0.2.1 — 2026-07-19

- Frontmatter приведён к спецификации Agent Skills: `version` перенесена в `metadata` (валидатор ругался на верхнеуровневый ключ). Формат frontmatter теперь проверяют тесты в CI: допустимые ключи, name, длина description, версия внутри metadata.
- Один код — один объект в отчёте: варианты одного правила агрегируются (слитная и разорванная формы S17, эмодзи- и болд-декор S22); счётчики суммируются, severity берётся строже. Добавлен тест уникальности кодов.
- S26: исправлен подсчёт тире в текстах с диалогом — реплики диалога больше не вычитаются из авторских пауз (баг занижал счёт и прятал флаг). Смешанный случай закреплён тестом.

## 0.2.0 — 2026-07-19

- Коды офлайн-аудитора синхронизированы со справочниками `references/`: нумерация S/R/U теперь совпадает с заголовками каталогов, расхождение ловит отдельный тест в CI.
- Новые проверки скрипта: разорванный контраст «Это не X. Это Y.» (S17), повтор ровных троек «X, Y и Z» (S18), хвост хештегов с платформенным порогом (S25), плотность тире как паузы (S26) — сам знак по-прежнему не запрещается.
- Русский профиль в скрипте дополнен правилами из каталога: пустые контейнеры (R07), двойное усиление (R09), повтор «не только…, но и…» (R10); метатекст переехал на канонический код R08.
- Новые флаги CLI: `--fail-on P0|P1|P2` (ненулевой код выхода для пайплайнов) и `--platform neutral|telegram|instagram`.
- Разбивка на предложения понимает телеграм-строки без завершающей точки; blockquote-цитаты (`>`) больше не аудируются как текст автора.
- Кодировки: UTF-16 с BOM читается корректно, UTF-16 без BOM даёт честную ошибку вместо тихой каши; UTF-8 и Windows-1251 как раньше.
- «Даний» (U01) больше не срабатывает на русское «дана» в смешанных текстах.
- В каталог `shared-patterns.md` добавлены разделы S25 «Хвост хештегов» и S26 «Тире как универсальная пауза».

## 0.1.0 — 2026-07-19

- Первая публикация: SKILL.md с четырьмя режимами и факт-замком, каталоги паттернов (общий, русский, украинский, площадки), офлайн-аудитор без зависимостей, тесты, CI для Windows и Linux.
