# Человеческий корпус

Положите сюда свои реальные посты: один пост — один файл `.txt` в UTF-8. Файлы `*.txt` из этой папки не попадают в git (личные тексты не должны утекать в публичный репозиторий).

Затем запустите:

```bash
python scripts/eval_corpus.py
```

Отчёт покажет, сколько ложных флагов правила вешают на живой текст, и какие правила ослаблять.
